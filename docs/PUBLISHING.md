# GitHub 项目与更新方式

- 展示标题：**Recommender Sys & Web Mining**
- GitHub 账号：`KZXPLYS`
- 仓库：https://github.com/KZXPLYS/recommender-sys-and-web-mining
- 本地文件夹：`CSE258`（无需与远端仓库同名）。

## 内容整理

完成的实现与实验入口分别放在 `HW1/`、`HW2/`；课程模板归档在 `archive/templates/`。数据集、缓存与本地备份不上传。原始工作文件保留在本地 `.local-backup/`。

## 后续更新

本地编辑不会自动同步到 GitHub。可以在仓库网页中上传变更文件并提交；也可以在配置 Git 身份和认证后，克隆仓库，再通过 `git add`、`git commit` 和 `git push` 更新。上传时保留目录结构，并检查不要包含数据集或本地备份。网页上传不会自动应用本地 `.gitignore` 规则。
